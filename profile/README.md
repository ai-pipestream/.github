# Pipestream AI

**Open-source software that assists with human understanding.**

We're a small collaboration of engineers working on distributed semantic search,
document understanding, and the open infrastructure that connects them. We build
in the open and contribute upstream — to Apache OpenNLP, Tika, and Lucene, to
Quarkus, and to the gRPC and Docling ecosystems. Everything we release is
licensed under Apache 2.0 or MIT.

- 🔎 [distributed-search](https://github.com/ai-pipestream/distributed-search) — gRPC distributed semantic search with collaborative HNSW KNN across shards
- 🧪 [Public Research](https://ai-pipestream.github.io/#research) — collaborative distributed HNSW search
- 🌐 [pipestream.ai](https://pipestream.ai)
